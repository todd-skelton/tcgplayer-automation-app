# Slab Pricing workspace

`/slab-pricing` composes the existing identity, inventory, evidence, review and recommendation use cases. It adds no runtime dependency, database table or provider-specific browser code. React Router splits the page from TCGplayer routes; comp review is a separate lazy component. The new read-only workspace endpoint loads one identity, its cache status and latest saved recommendation. Only explicit actions request provider work. Inventory uses 25-row cursor pages and evidence uses 50-row pages; full sale detail is requested only from a displayed source revision.

Certificate lookup keeps the reported owned grade separate from exploratory PSA research. Exploring PSA 10 for certificate 110185364 creates a detached research target; it does not confirm or update the reported PSA 1 Hitmonlee identity. Alt's all-grade cache key is shared across research grades. eBay keys use the research target's group. Comp decisions, calculations and overrides require the confirmed owned identity; a selected listing must be explicitly assigned that identity before calculating. Other graders retain their owned grading labels rather than inheriting PSA mappings.

The inventory panel accepts the existing CSV format: required `item_id,title,price,currency,quantity,state,format`; certificate columns are `grader,certificate_number`. A listing without a certificate can be opened, followed by a certificate lookup, identity confirmation and explicit listing assignment with a reason. CSV/manual imports remain partial snapshots. The production seller adapter remains in draft PR #38 pending keyset activation; the page does not claim seller OAuth is configured.

Cache polling occurs only while requested jobs are queued/running. Status reloads preserve cost inputs, comp pagination and review drafts. Identity changes from another session require reopening the certificate. Saved recommendations remain visible with stale indicators when identities, decisions, selected revisions, source freshness or cost inputs change. Recalculation clears the local decision-version marker only after reading back the saved result. Source-row screening and final cross-source event decisions are presented separately, including recency weights and exclusion reasons. A reviewed ask is displayed independently of the original model's ask/profit assumptions.

## Validation

- `npm test`, `npm run typecheck`, `npm run build`.
- `npx tsx app/features/ebay-slab-pricing/research/slabResearch.integration.test.ts`: disposable local PostgreSQL schema; 50-listing pagination, research/owned grade isolation, no remote calls on warm reads, correction invalidation and recalculation.
- `npx tsx app/features/ebay-slab-pricing/inventory/slabInventory.integration.test.ts`: revision conflicts, identity assignments, partial imports and 5,000-row workload.
- Chrome: real certificate 110185364 displayed PSA 1.0; PSA 10 exploration preserved an unsaved identity note. Both providers returned live evidence; Alt displayed capped coverage (194 source observations, 123 within the selected window), with 50-row navigation. Status reload preserved a typed acquisition cost and the second comp page. A labelled local copy of the historical 50-listing sample paginated in two pages and supported arrow-key grid navigation; placeholder quantities were explicitly labelled, not imported as current Pokebash stock.
- An isolated synthetic UI identity/evidence fixture exercised acceptance, exclusion, stale-result marking, recalculation and override readback. Four events produced a $100–$120 range/$110 ask; excluding one changed the result to three events/$110–$130/$120 ask. A $125 reviewed ask retained the original $120 model ask and unknown proceeds/profit. Synthetic data are not market evidence.

Adversarial review fixes included stale markers that survived recalculation, preserving drafts during status reload, retrying polling after a read failure, explicit identity assignment for certificate-less listings, bounded cursor pages, separate reviewed/model prices, unknown-currency handling and using the Chicago date rather than tomorrow's UTC date. Production build measurements before final formatting: about 10 KB gzipped for the slab page and 7 KB for lazy comp review, in addition to existing shared React/MUI/grid chunks. Existing MUI build warnings persist. No deployment or eBay listing-price writes are part of this change.
