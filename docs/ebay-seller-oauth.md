# Production seller inventory adapter (pending live activation)

The inventory/CSV core is merged separately in PR #42. This adapter adds `import-ebay` and `refresh-listing` to `/api/slab-inventory`, plus a boolean `sellerOAuthConfigured` in its loader. It exposes only GetUser, GetMyeBaySelling and GetItem reads; no inventory migration or listing-write API is called.

Production credentials belong only in server configuration: `EBAY_SELLER_CLIENT_ID`, `EBAY_SELLER_CLIENT_SECRET`, `EBAY_SELLER_REFRESH_TOKEN`. Local configuration uses the existing ignored `.env.development.local` and requires a process restart. The per-run transport exchanges the refresh token once for the base Trading scope, uses fixed production origins and manual redirects, and limits a run to thirty reads, a request to 25 seconds and a response to 2 MiB. The server-only XML parser validates responses, preserves certificate strings and rejects DTD/entity declarations.

GetMyeBaySelling is used to cover listings created manually through My eBay; the Inventory API is not assumed to enumerate them. Imports verify the authenticated username, read at most twenty 200-listing pages, preserve partial coverage, check totals/duplicates and reject warning/error acknowledgements. GetItem details are lazy, field-selected and independently checked against the requested seller and item. Variations use stable specifics-derived keys, not SKU. Numeric CGC grades do not imply Gem Mint/Pristine labels.

References: [GetMyeBaySelling](https://developer.ebay.com/devzone/xml/docs/reference/ebay/GetMyeBaySelling.html), [GetItem](https://developer.ebay.com/devzone/xml/docs/reference/ebay/GetItem.html), [account-deletion activation](https://developer.ebay.com/develop/guides/sell/marketplace-user-account-deletion).
